About Damolda

Objects for
keeping what matters.

DAMOLDA begins with the small things people do not want to lose: a season, a walk, a table, a color, a piece of a day.

Not decoration first.
A place first.

We make forms that help personal memories become visible in a room. Shell, Sheets, and Stone are not finished stories. They are quiet structures for arranging what each person chooses to keep.

01 / Memory

Personal, not loud.

The object should not explain everything. It should leave enough space for the owner’s memory to enter.

02 / Form

Simple, but held.

We begin with restrained shapes: a shell, a sheet, a stone. Each form gives a different weight to what is kept.

03 / Room

Made to live with.

DAMOLDA is not only for display. It is for tables, shelves, corners, and the ordinary places where memory actually stays.

Quietly kept. Not because it is small, but because it matters.
